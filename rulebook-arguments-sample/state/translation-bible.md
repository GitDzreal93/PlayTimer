# Translation Bible

## Project identity

- Book title: A Rulebook for Arguments, Fifth Edition / 《论证规则手册》（暂定）
- Author: Anthony Weston / 安东尼·韦斯顿
- Source edition: EPUB, Hackett Publishing Company, 2017; ISBN 9781624667398
- Genre/domain: 通俗论证写作、批判思维、逻辑入门
- Target language: Simplified Chinese
- Target readership: 希望学习英文论证写作和批判思维的中文读者
- Output mode: Chinese-only + interactive bilingual HTML sample

## Translation thesis

这本书的中文译文应当保留原作“规则手册”的清楚、短促和可操作性。作者不是在写沉重的逻辑学教材，而是在像一位好老师那样，用轻巧的例子带读者看清论证怎么成立、怎么乱掉。中文要像一本自然的中文写作书：直接、明快、有一点口语弹性，但不油滑。关键术语如 argument、premise、conclusion、reason 要稳定；普通说明句则要优先读顺，少用“进行、构造、陈述、因此、主张”等硬邦邦的翻译腔。原文中故意啰嗦的坏例子可以保留笨重感，但要笨得可读，让读者看出它的问题，而不是被译文绊倒。

## Global style rules

- Literalness / idiomatic freedom: 术语和论证关系从严，普通说明句优先自然中文，不照搬英文句序。
- Sentence length: 保持短句推进感；英文长句可拆、可调顺序，只要逻辑关系不变。
- Paragraph policy: 保持源文段落对应，便于双语核对。
- Pronoun policy: 中文中自然省略重复主语；涉及前提、结论、理由的指代时保留清楚。
- Passive voice policy: 尽量转为自然主动句，除非被动关系本身重要。
- Quotation marks: 中文主体用中文引号；保留英文术语或公式时用原文形式。
- Dashes / ellipses: 破折号可保留为中文破折号；省略号用中文语境自然处理。
- Numbers: 保留章节号、规则号、经文章节号、日期数字。
- Foreign terms in parentheses: 首次或概念敏感处可保留英文，如 resolve。
- Chapter-title style: 章标题短而明确，小节标题尽量像中文写作建议，例如“先理清……”“按……展开”。
- Footnotes/endnotes: 保留脚注编号和来源信息；网址不翻译。

## Terminology

| Source term | Canonical Chinese | Allowed variants | Forbidden/avoid | Rationale / context |
|---|---|---|---|---|
| argument | 论证 | 一个论证 | 争论、参数 | 本书核心概念，指由理由支持结论的结构 |
| premise | 前提 | 主要前提 | 假设（除非语境为 assumption） | 逻辑/论证术语 |
| conclusion | 结论 | 主张（特定语境） | 结尾 | 论证所要证明的陈述 |
| reason | 理由 | 根据 | 原因（除因果语境） | 与 premise 紧密相关但更口语 |
| evidence | 证据 | 依据 | 材料 | 保留论证支持力度 |
| short argument | 简短论证 | 短论证 | 小作文 | 章题和全书分类术语；面向普通读者时“简短论证”更自然 |
| reliable premise | 可靠的前提 | 站得住的前提 | 真实前提（过窄） | 强调可接受性与支持性 |
| overtone | 情绪色彩 | 词语色彩、情绪暗示 | 弦外之音（此处过窄） | 指词语带来的情绪暗示 |
| substance | 实质 | 真正的理由、实际内容 | 内容（太泛） | 与 overtone 对照 |
| parallel construction | 平行结构 | 相似结构 | 排比（可能过窄） | 写作手册术语 |
| signposts | 路标 | 过渡提示 | 标志牌（字面感过重） | 指帮助读者识别论证结构的提示语 |
